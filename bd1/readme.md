# APL121 · Бие даалт №1 — Code Quest
## Сэдэв №16 — Цагийн хөлс

### Программын тайлбар
7 хоногийн өдөр бүрийн ажилласан цаг, цагийн хөлс болон суутгалын хувийг оруулж, нийт цалин ба гар дээр авах цалинг тооцоолно. Мөн хамгийн олон цаг ажилласан өдрийг олно.

### Файлууд
- `quest.fprg` — Flowgorithm программ.
- `flowchart.png` — Блок схемийн зураг.
- `pseudocode.md` — Алгоритмын псевдокод.
- `main.c` — C хэл дээрх программ.
- `tests.md` — Тестийн оролт, хүлээгдэж буй болон бодит гаралтууд.
- `README.md` — Программын тайлбар, ажиллуулах заавар.

### Тооцооллын дүрмүүд
1. Өдөр бүрийн ажилласан цаг 0–24 хооронд байна. Энэ хязгаараас гарсан тоон утгыг дахин оруулуулна.
2. Бутархай цаг оруулж болно.
3. Нийт ажилласан цаг 40 хүртэл бол энгийн тарифаар бодно.
4. 40 цагаас давсан хэсгийг цагийн хөлсний 1.5 дахин нэмэгдүүлсэн тарифаар бодно.
5. Суутгалыг нийт цалингаас өгсөн хувиар тооцно.
6. Хамгийн олон цаг ажилласан өдөр хэд хэд байвал эхний өдрийг сонгоно.
7. Бүх өдөр 0 цаг ажилласан бол хамгийн их ажилласан өдрөөр 1-р өдөр гарна.

Томьёо:
- Нийт цаг ≤ 40:
  Нийт цалин = Нийт цаг × Цагийн хөлс
- Нийт цаг > 40:
  Нийт цалин = 40 × Цагийн хөлс + (Нийт цаг − 40) × Цагийн хөлс × 1.5
- Гар дээр авах цалин = Нийт цалин − Нийт цалин × Суутгалын хувь / 100

### Оролт
Дараах дарааллаар тоон утгууд оруулна:
1. 1–7-р өдрийн ажилласан цаг.
2. Цагийн хөлс.
3. Суутгалын хувь.

Цагийн хөлсийг сөрөг биш, суутгалын хувийг 0–100 хооронд оруулна. Одоогийн код эдгээр хоёр утгын хязгаар болон үсгэн оролтыг шалгахгүй.

### C программыг ажиллуулах
Terminal дээр `main.c` байгаа хавтас руу орж дараах командуудыг ажиллуулна:

```bash
gcc -Wall -Wextra main.c -o main
./main
```

### Flowgorithm программыг ажиллуулах
Flowgorithm дээр `quest.fprg` файлыг нээгээд Run дарна.

### Жишээ оролт
Өдөр бүрийн цаг: 8, 8, 8, 8, 8, 5, 0.
Цагийн хөлс: 10000.
Суутгал: 10%.

```text
8
8
8
8
8
5
0
10000
10
```

### Жишээ гаралт
Дээрх оролтын үед үр дүнгийн гол мөрүүд:

```text
7 хоногт нийт ажилласан цаг: 45.00
Хамгийн их ажилласан өдөр: 1
Тухайн өдрийн ажилласан цаг: 8.000000
Нийт цалин: 475000.00
Гар дээр ирэх цалин: 427500.00
```

Тооцоолол:
- Энгийн цагийн цалин: 40 × 10000 = 400000.
- Илүү цагийн цалин: 5 × 10000 × 1.5 = 75000.
- Нийт цалин: 475000.
- Суутгал: 475000 × 10 / 100 = 47500.
- Гар дээр авах цалин: 427500.
